创建任务

选择来源与目标，任务会进入现有下载队列。

连接 API 后可创建下载或存储间传输任务。

直链和视频可填写多个地址；磁力链接请使用 Aria2。

源存储必须支持列目录和读取文件。

任务动态

每 5 秒自动刷新，仅显示通过 HTTP API 创建的任务。

↗先连接 API

输入配置文件中的 API Token，即可加载存储、任务类型和运行状态。

Bot Relay

监听频道 Deep Link，并把目标 Bot 返回的媒体直接加入用户的 SaveAny 队列。

使用该用户的默认存储、默认目录、规则和冲突策略；处理状态也发给该用户。

Userbot 账号必须已加入来源频道。配置保存到数据库并即时生效，无需重启。

Relay 路由

每个来源频道与目标 Bot 只能配置一条路由。

⌁先连接 API

连接后可新增、编辑、启停或删除 Relay 路由。

全局配置

直接编辑当前本地 TOML；保存前会校验，成功后服务自动重启并加载新配置。

Token、密码和密钥会显示为 __SAVEANY_REDACTED_*__；保持该值即可保留原密钥，也可以直接填入新值。

环境变量和 CLI 参数优先级高于 TOML；被覆盖的字段即使写入文件，也不会成为当前有效值。
